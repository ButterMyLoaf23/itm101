The web, but in 3D

Make the browser come alive.

Three.js is a JavaScript library that makes it easier to create and display animated 3D graphics in the browser — without needing to learn WebGL from scratch.

See the basics ↓ Visit threejs.org ↗
01 / A quick definition

3D graphics, made approachable.

At its heart, Three.js gives you a scene, a camera, and a renderer. Add lights, materials, and objects to that scene, then render it frame by frame to create interactive experiences that run right inside a web page.

01Scene — the world where your objects live.
02Camera — the point of view your audience sees.
03Renderer — turns your 3D scene into pixels.
02 / The toolkit

Small building blocks. Big possibilities.

/ 01

Scenes & objects

Build worlds from meshes, geometry, and materials. From a simple cube to a detailed product model, every object has a place in your scene.

/ 02

Motion & interaction

Animate with a render loop, respond to pointer input, and create immersive interfaces that feel alive and tactile.

/ 03

Web-ready power

Load models, textures, and shaders directly in the browser. Three.js handles the hard WebGL work so you can focus on the experience.

03 / Your first scene

Start with three lines.

Once the library is loaded, the core loop is wonderfully compact. Add a camera, put something in the scene, and ask the renderer to draw it.

Read the docs ↗
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, width / height);
const renderer = new THREE.WebGLRenderer();

// add a shape and render the scene
scene.add(mesh);
renderer.render(scene, camera);
